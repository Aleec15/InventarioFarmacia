# Sistema de Inventario para Farmacia

Este es un programa sencillo en Java desarrollado como parte del curso de Programación 1.

## Descripción

El sistema permite llevar el control básico del inventario de una farmacia mediante una interfaz gráfica. Está construido con Java y Swing, utilizando Maven como sistema de gestión de proyecto.

## Funciones principales

- Registrar productos
- Consultar productos por código
- Ver inventario
- Vender productos
- Actualizar precios
- Salir del sistema
